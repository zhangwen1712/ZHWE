# Map data attribution

- Chinese city and regional boundary geometries are selected from [China-GeoData](https://github.com/Supeset/China-GeoData), MIT License, Copyright © 2025 圈集; see `china-geodata-MIT.txt`.
- Pingyao county boundary is selected from [geoBoundaries CHN ADM2](https://www.geoboundaries.org/), source National Administration of Surveying, Mapping and Geoinformation of China / Revolutionary GIS, Open Data Commons PDDL v1.0.
- Bangkok and Phuket provincial boundaries are selected from [geoBoundaries THA ADM1](https://www.geoboundaries.org/), source OpenStreetMap / Wambacher, Open Data Commons ODbL 1.0. OpenStreetMap attribution and database license: https://www.openstreetmap.org/copyright. This subset is a derivative database under ODbL; its source geometries and names remain available in `public/map/visited-regions.geojson`.
- The world basemap uses [Natural Earth 1:110m Admin 0 countries](https://www.naturalearthdata.com/), which is public domain.

- The detailed basemap is provided by [OpenFreeMap](https://openfreemap.org/) and uses [OpenMapTiles](https://openmaptiles.org/) and OpenStreetMap data. See the interactive map attribution.
